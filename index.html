🛠️ Common Hiccups and Fixes

The download stops partway through

Large files sometimes get interrupted by a dropped connection. Delete the partial file, refresh the page, and start again. If it keeps failing, try a different browser.

Pegasus does not show any new games

This almost always means the folder was added at the wrong level. Point Pegasus at the main catalog folder itself, not at a subfolder inside it. Then trigger a fresh scan.

Titles appear with blank covers

Artwork needs to stay next to the metadata it belongs to. If you moved files individually instead of moving the whole folder, put them back in the original arrangement and rescan.

Windows warns about the extracted files

This is the standard Windows caution for files that came from the internet. Right-click the extracted folder and check its properties for an Unblock option if you see one, then try again.

Everything is slow after adding the catalog

A catalog of this size takes a moment on the first load while artwork is cached. Leave Pegasus open for a few minutes and it settles down. Later launches are much faster.
